# warpcsv

Warp HTML/Markdown csv fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/warpcsv/

## Install / run

```bash
git clone https://github.com/theworker02/warpcsv.git
cd warpcsv
node src/cli.js
node --test
```
